# Прямая связь с покупателями — 29 октября 2026

Реализация подготовлена в локальном проекте. Публикация на GitHub Pages не выполнялась.

**Обновление 30 октября 2026.** Внешний вид кнопок переработан: официальные знаки Telegram и Viber в круглых цветных бейджах, анимации наведения и нажатия. Панель помощи Viber на телефоне поднимается снизу. Ссылки, черновики и резервные варианты те же. Описание и результаты проверки в браузере: [RAPHTALIA-DESIGN.md](RAPHTALIA-DESIGN.md). Строки ниже про отсутствие визуальной проверки относятся к версии от 29 октября.

## Что изменилось

- В шапке доступны Telegram и Viber. До 900 px используются узнаваемые значки с доступными названиями; минимальный размер кнопки — 44 × 44 px.
- На главной обновлён блок заказа; в каталоге и категориях появился компактный блок помощи с выбором. Мини-карточки товаров сохранены без дополнительных кнопок.
- На страницах товаров контакты размещены рядом с ценой, в повторном блоке заказа и в существующей мобильной панели. Telegram получает черновик с названием, артикулом и канонической ссылкой на товар. Текст можно скопировать для Viber.
- Форма SLA обновляет черновик Telegram при изменении полей. Сохранены копирование запроса, ручное копирование при отказе буфера обмена и вариант без JavaScript.
- OLX остаётся дополнительным способом оформления; существующие ссылки на объявления и профиль сохранены. Условия доставки не изменены.
- Используются локальные SVG-значки, существующие кнопки и переменные оформления. Добавлены плавные состояния наведения, нажатия и появления, поддержка reduced motion, клавиатуры и безопасных отступов экрана.

## Ссылки и запасные варианты

- Telegram: `https://t.me/M4245877`. Параметр `text` передаёт редактируемый черновик конкретному получателю; сообщение самостоятельно не отправляется.
- Без установленного Telegram: `https://web.telegram.org/k/#@M4245877`. Для переписки нужен вход в Telegram Web. Эта ссылка открывает контакт; черновик в веб-версию не переносится, поэтому запрос можно скопировать.
- Viber: `viber://chat?number=%2B380989073072`. Обработку ссылки выполняют браузер, ОС и установленный Viber.
- При нажатии Viber сразу вызывается нативная ссылка и появляется закрываемая подсказка с номером, копированием, установкой приложения и альтернативами Telegram. Скрипт не определяет наличие приложения и не перенаправляет посетителя по таймеру.
- Без JavaScript ссылки работают как обычные ссылки; номер и инструкция Viber доступны в раскрываемом блоке подвала.

Документация: [ссылки Telegram](https://core.telegram.org/api/links), [маршрутизация Telegram WebK](https://github.com/morethanwords/tweb/blob/master/src/lib/appImManager.ts), [установка Viber на компьютере](https://help.viber.com/hc/en-us/articles/9084593040285-Set-up-Viber-on-your-desktop).

## Проверки

- `npm run check`: без ошибок и предупреждений; остаются 6 существующих информационных подсказок Astro/TypeScript.
- `npm test`: 86 тестов, включая реальную производственную сборку, проверку всех 49 товаров, ссылок, черновиков, запасных вариантов, сохранности OLX, копирования и обработки Escape.
- Проверены HTTP 200 для контакта Telegram, контакта с черновиком, Telegram Web и страницы загрузки Viber. HTML Telegram передаёт параметр черновика в ссылку приложения.
- Визуальная проверка в браузере и на физических телефонах/планшетах не выполнена: в сессии недоступны браузеры и канал управления компьютером. Открытие Viber на зарегистрированный номер и переписка в приложениях не проверялись; тестовые сообщения не отправлялись.

Для ручной приёмки: проверить главную, категорию, товар и SLA на ширинах 320, 390, 768, 1024 и 1440 px; переходы с установленными приложениями и без них; Telegram Web после входа; копирование при запрете буфера обмена; клавиатуру, мобильную панель и reduced motion.

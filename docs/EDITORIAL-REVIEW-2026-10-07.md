# Редакція текстів сайту від 7 жовтня 2026 року

Повна редакція впроваджена в поточне дерево вихідного проєкту. Це внутрішній
звіт; він не потрапляє до публічних сторінок Astro. Початкове робоче дерево
було чистим, інструкцій AGENTS.md у проєкті та його батьківських каталогах
не виявлено. Бренд залишається «3D Друкарня».

## Матеріали та охоплення

Повністю прочитано «Рафталия.docx», включно з таблицями, примітками й джерелами.
Канон, психологічні інтерпретації та художні реконструкції розділено.
З документа взято практичну турботу, щирість, стриманість, гідність і зрілу
самостійність; сюжетні відносини не перенесено до відносин із покупцем.

У проєкті 63 індексовані сторінки, 404 та 8 старих переадресацій категорій.
Російської версії, пошуку, сортування, кошика та конфігуратора немає.
Наявні фільтри працюють на головній; виконання товарів показані інформаційними
списками. Нові сторінки, інтерактивні функції та мовні версії не створювалися.

Усі товари зараз використовують спільний профіль продавця OLX, бо `orderUrl`
не заданий. Текст CTA та пояснення відповідають цьому переходу. SLA-форма
готує й копіює запит; повідомлення магазину користувач надсилає вручну на OLX.

## Голос та приклади

Українською використано «ти», англійською — природне особисте «you».
Перша особа Рафталії вибіркова й жіноча. Теплота найбільш помітна у вступах;
у товарі вона передається конкретними перевірками та чесними обмеженнями.
Виготовлення та випробування не приписуються персонажу.

| Місце | До | Після |
| --- | --- | --- |
| Головна | «Стійки, NAS-корпуси, кріплення й аксесуари для домашньої лабораторії» | «Рада, що ти тут. Я Рафталія, і мені хочеться, щоб твоя техніка мала зручне місце» — далі конкретний асортимент |
| Порожній фільтр | «У цій категорії поки немає товарів. Оберіть іншу категорію…» | «За цим фільтром товарів немає. Спробуй іншу категорію або “Усі товари”…» |
| P6, Intel NUC | «…більшість NUC… повинні підійти» | «Я не хочу обіцяти тобі точну посадку лише за поколінням…» — далі перевірка розмірів пристрою |
| P45, Voice PE | «Це виконання не слід замовляти…» | «Якщо тобі потрібен цей порт без зняття пристрою, v2 не підходить» |

| SLA, скопійовано | «Запит скопійовано…» | «Текст скопійовано. Запит ще не надіслано…» |

Внутрішня пам’ятка для нових товарів: [RAPHTALIA-VOICE.md](RAPHTALIA-VOICE.md).

## Перевірки

- `npm run validate:data` — 49 товарів, категорії, поради й перехресні посилання проходять.
- `npm run prices:check` — усі 33 розрахункові ціни відповідають політиці; 16 попередніх орієнтирів збережені.
- `npm run check` — 0 помилок, 0 попереджень, 7 наявних інформаційних підказок Astro/TypeScript.
- `npm test` — фінальний запуск: 77/77, включно з реальною production-збіркою й усіма перевірками артефакту.
- `npm run check:build` — метадані, JSON-LD, ціни, маршрути, внутрішні посилання, fallback зображень проходять; той самий checker виконується й у фінальному `npm test`.
- `npm run check:catalog` — HTTP-перевірка 49 карток, 10 нових товарних сторінок, 4 категорій, галерей, sitemap і кнопок замовлення проходить.
- `npm run indexnow:dry-run` — коректний список 63 URL; нічого не надіслано.
- Окреме read-only порівняння всіх JSON із Git HEAD: захищені поля, кількість виконань і рівні попереджень незмінні; обидва описи відредаговані для кожного товару, UTF-8 цілий. Найдовший короткий опис — 165 символів.
- Виконано клієнтські скрипти меню й SLA у тестовому DOM: українське/англійське відкриття та закриття меню, початковий запит, оновлення, успішне копіювання, відмова та відсутність clipboard. Запити не надсилалися.
- Незалежна взаємна вичитка всіх товарів і повторна вичитка всіх порад. Пошук старих форм звертання, пошкодженого кодування та сюжетних імен не знайшов залишків у `src`.
- `git diff --check` — без помилок. Ціни, фото, структура каталогу, URL та зовнішні посилання збережені.

Обмеження перевірки: браузерний інструмент повернув порожній список доступних
поверхонь; in-app браузер недоступний. Візуальний прогін на широкому й мобільному
екранах та ручні кліки у браузері не виконані. Перевірено адаптивні правила
наявної верстки в коді: повні описи й товарні CTA дозволяють перенесення,
короткі описи лишаються в межах існуючої довжини. Каталожне обрізання до
2–3 рядків є наявним дизайном; повний текст доступний на товарній сторінці.

Початкові запуски `npm test` і `npm run build` зупинилися через sandbox
`spawn EPERM`. Дозволений повтор штатного тестового раннера з дочірніми
процесами пройшов, разом із production-збіркою.

## Факти, які ще потрібно уточнити

- P11: точна монтажна ширина та габарити 12-дискового 3U-корпуса. Поради більше не обіцяють його сумісність із 10-дюймовою стійкою.
- P25: число портів окремо для TL-SF1006P і TL-SG608E. Старе спільне «шестипортові» прибрано; назви й заявлені моделі сумісності збережені.
- P26: фізична перевірка посадки зазначених P350/P360/M70q/P3 Tiny; P30: перевірка жорсткості й посадки 130-мм полиці.
- P28/P29: у строках залишена умова підтвердження дозволу автора моделі. Її фактичний статус має уточнити власник; це не стосується дозволу на образ Рафталії.
- P40–P49: фізична посадка, вага, готові габарити й строки друку, які вже позначені непідтвердженими. Додатково P42 — відстань між монтажними вушками; P45 — гвинти та зазор USB-C; P46 — товщина накопичувачів; P47 — метизи V3 та спільна посадка комплекту; P48 — навантаження; P49 — розміри комірок.
- Без підтвердженої ваги/переглянутого цінового профілю залишаються P7, P10, P14, P16, P38–P49. Попередні ціни не змінені.
- Публічні умови оплати, повернення та гарантії в джерелах відсутні. Нових строків або зобов’язань не вигадано.

Уточнення зібрані лише тут; редакційних доручень на сторінках не розміщено.

## Готовий результат і публікація

Редакція знаходиться у `src/`; готовий статичний артефакт — у `dist/`.
Публікація не виконувалася. Чинний процес: push у `main` запускає
`.github/workflows/deploy.yml`, який перевіряє проєкт, збирає та публікує
GitHub Pages. Зміни залишені в робочому дереві для перегляду.

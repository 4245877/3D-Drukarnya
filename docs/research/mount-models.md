# Моделі кріплень і VESA-корпуса

Перевірено 4 жовтня 2026 року. Усі чотири картки збережено як приховані чернетки. Відомості про моделі, фотографії та виробничу готовність перевіряються окремо.

## Джерела та спосіб перевірки

Основні джерела: [Glen Bayley / Printables 1422338](https://www.printables.com/model/1422338-smlight-slzb-06-slzb-mr-wall-mount), [delphiki / Printables 1132964](https://www.printables.com/model/1132964-home-assistant-voice-pe-wall-mount), [оновлена delphiki v2 / MakerWorld 943189](https://makerworld.com/en/models/943189#profileId-909273), [meie1kyl / Printables 378810](https://www.printables.com/model/378810-double-25-to-35-ssd-hdd-bay-adapter), [mrlinux2u / Printables 644063](https://www.printables.com/model/644063-raspberry-pi-5-case-designed-for-active-cooler-and).

Звичайні HTML-сторінки Printables/MakerWorld повертали Cloudflare 403. Публічні API працювали без облікового запису: Printables `https://api.printables.com/graphql/`, MakerWorld [дані моделі 943189](https://makerworld.com/api/v1/design-service/design/943189). Printables GraphQL повернув назви, авторів, ліцензії, опис, точні назви/ID файлів і `images.filePath`; публічний `getDownloadLink` надав посилання для читання STL. Нічого авторам не надсилалося.

Завантажено шість STL для перевірки геометрії: P43, Printables P45, P46 і три деталі P47. Ідентифікатори, SHA-256, розміри файлів та координатні межі збережено у [mount-geometry.json](mount-geometry.json). STL не містить одиниць вимірювання: прийнята друкарська інтерпретація координат у мм. Це габарити цифрової геометрії, не вимірювання відбитків. Маса і час друку в картках не заявляються.

## P43 — SMLIGHT, 249 грн

Обрано одну гвинтову рамку `SLZB-06 wall mount.stl` (ID 5986153). Також доступні `SLZB-06 wall mount.3mf` (5986014), `.step` (5986151) і `.f3d` (5986152). STL містить одну зв'язану геометрію; межі 160,2 × 27,46 × 6,6. Автор рекомендує PLA/PETG; для чернетки обрано PETG.

Автор підтверджує SLZB-06, 06M, 06Mg26, 06P7, 06P7U, 06U, MR1, MR1U, MR2, MR3, MR3U, MR4, MR4U, MR5U, MRW10. Інші модифікації не заявляються. Рамка з пружними защіпками, автор заявляє збереження вентиляції. Дві потайні точки кріплення видно на авторських фото; потрібні два #6 / #8, довжина та дюбелі залежать від стіни. Вони не входять. Магнітна модель №1646877 — окремий ремікс, не цей товар.

Модель: Glen Bayley, CC BY-SA 4.0; комерційне використання допускається за її умовами. Окремого дозволу на комерційне використання фотографій не знайдено. Потрібні пробний друк, перевірка зачепів із конкретним SLZB та вибір настінного кріплення.

## P45 — Voice PE v2, 279 грн

MakerWorld API підтвердив саме `Home Assistant Voice PE wall mount v2`, автор delphiki, модель 943189, профіль 909273. Опис v2 прямо підтверджує уточнену посадку, меншу товщину та видалення вирізу Grove. Вибрано один тримач `Home Assistant Voice PE wall mount v2.stl`, 190084 байти; API заявляє STL і авторський профіль 3MF. Авторський профіль використовує PLA. Його 23 г та 2802 с є прогнозом слайсера A1, не виміряними параметрами товару; у ціну за масою їх не перенесено.

Чотири потайні монтажні отвори та кабельний виріз видно на рендері. Автор не задав точного комплекту настінних гвинтів. Голосовий пристрій, кабелі, блок живлення, гвинти і дюбелі не входять.

Поточна ліцензія API — `BY-NC-SA`; номер версії Creative Commons там не вказано, тому картка посилається на ліцензію самої сторінки. Printables має CC BY-NC-SA 4.0 та файли `Home Assistant Voice PE wall mount.stl` / `.3mf`. Завантажений Printables STL має межі 87 × 87 × 17,5 та однаковий із v2 розмір файла, але це не доводить тотожність двох STL. Його розміри не перенесено в картку v2. Потрібні завантаження/перевірка саме v2, пробне складання, підтвердження гвинтів, доступу USB-C та дозволів на продаж і фото.

[Авторський допис Home Assistant](https://community.home-assistant.io/t/wall-mount-for-the-home-assistant-voice-pe/820162) додатково підтверджує посилання на v2. Його старі фото не використано: відповідність v2 невідома, а [умови форуму](https://www.home-assistant.io/tos/) §3 задають користувацьким матеріалам CC BY-NC-SA 3.0.

## P46 — два диски 2,5″ → відсік 3,5″, 349 грн

Обрано одну перфоровану стандартну рамку `double 2.5 to 3.5.stl` (1660027), відповідну фото автора. Координатні габарити 119,834 × 101 × 20; одна зв'язана геометрія. PETG — вибір майстерні для запланованого друку, не перевірений авторський профіль.

Інші файли: `2_5_to_3_5_drive - noHEX.stl`; `2_5_to_3_5_drive - EXTRA HEIGHT.stl` / `2_5_to_3_5_drive EXTRA HEIGHT.3mf`; `2_5_to_3_5_drive ADDITIONAL 3.5 INCH MOUNTING HOLES.stl` / `.3mf`. Висота 33 мм належить лише EXTRA HEIGHT, не вибраній рамці. Виріб утримує два накопичувачі 2,5″ у одному відсіку 3,5″; універсальна сумісність із будь-якою товщиною дисків чи безгвинтовими кошиками не підтверджена.

Ліцензія реміксу meie1kyl — CC BY-NC-SA 4.0. На первинній Printables-сторінці в походженні моделі вказано [оригінал Tadziurski / Thingiverse 1942247](https://www.thingiverse.com/thing:1942247) із CC BY-NC. Дозвіл автора реміксу сам по собі не вирішує права на оригінал. Потрібні дозволи на обидва рівні та фотографії. Не підтверджено точних кількості/типу/довжини гвинтів, максимальної товщини дисків і посадки у конкретний відсік; усе кріплення, накопичувачі та кабелі виключені.

## P47 — Pi 5 VESA V3, 599 грн

Фіксовано три друковані позиції: `rpi-case-vesa-base-nvme-V3.stl` (3053740), `rpi-case-nvme-lid.stl` (2993950), `rpi-case-power-switch.stl` (2993951). Автор явно замінив стару VESA-базу на V3 із додатковою вентиляцією. Поточна база має чотири точки VESA 75/100; старої V2 немає в актуальному API-переліку. 3MF для вибраних деталей не виявлено.

Автор проєктував сімейство для Raspberry Pi 5 з офіційним Active Cooler, а стандартну NVMe-кришку описує саме для Pimoroni NVMe Base. Це підтверджує авторський задум, але не виробничу перевірку цієї трійки у майстерні. GPIO, охолодження та складання V3 ще не випробувані. NVMe Base, Raspberry Pi, SSD, кулер і будь-яка інша електроніка виключені. PETG — запланований вибір майстерні.

Авторська базова BOM: 4 стійки M2.5 × 6, 4 стійки M2.5 × 20 male/female, 8 гвинтів M2.5 × 6. Для NVMe-виконання окремо вказані стійки M2.5 × 7 зі штатного комплекту Pimoroni між Pi та NVMe Base. Автор не навів окремої повної V3 BOM і розмірів гвинтів монітора; склад/порядок перевіряються при пробному складанні. Моніторні гвинти підбираються за його інструкцією, різьбою й допустимою глибиною. Усі метизи не входять.

Відсутні в комплекті: пилозахисна накладка, високі кришки, ніжки й вертикальні підставки. Габарити зібраного виробу не заявлено. У STL кришки й кнопки є кілька оболонок, що можуть торкатися без спільних вершин; їхня кількість не означає окремих деталей комплекту. Потрібна перевірка об'єднання/друку в слайсері. Геометричний огляд не є тестом міцності або складання.

Модель mrlinux2u — CC BY-NC 4.0. Потрібен дозвіл на комерційне використання й окремий розгляд прав на рендери/фото. Авторська `vesa-case.jpg` показує старе двоточкове виконання; червоні фото показують настільні ніжки. Вони не включені в галерею V3. Потрібні дозволені фото зібраної V3: обкладинка, монтаж із чотирма точками, порти й розкладка трьох друкованих деталей.

## Зображення та галереї

Галереї використовують чинний механізм проекту: масив `images`, перша позиція — обкладинка. URL взято з актуальних первинних API, не з вигаданих шляхів. Усі 11 вибраних посилань повернули HTTP 200; зображення завантажено у тимчасову папку та візуально оглянуто. Для P45 застосовано вже вживаний проектом MakerWorld-параметр `?x-oss-process=image/resize,w_1000/format,webp`: обидві відповіді HTTP 200 декодуються як WEBP, 1000 × 1108 та 1000 × 722. Повні посилання збережено у відповідних JSON.

## Что исправлено

1. **Незавершённая мутационная проверка.** Ошибка `focus radius: pattern not found` возникала при поиске текстового CSS-фрагмента во временном сценарии. Новый `scripts/check-design-regressions.mjs` находит глобальное правило `:focus-visible` независимо от его содержимого, вставляет дефект в отдельной временной копии и проверяет отказ нужного теста. Исходный checkout не мутируется; копия восстанавливается после каждого случая и удаляется в `finally`.
2. **Пять пропусков тестов.** Раньше проверки пропускали слишком широкий `minmax` в `px`, двойные кавычки вокруг селектора предка фильтров, кириллицу в верхнем регистре, текст после `https://` на той же строке и атрибут `style` в одинарных кавычках. Исправлены соответствующие проверки в `tests/design-system.test.mjs`. Все 15 намеренных дефектов обнаруживаются именно ожидаемыми тестами; чистый baseline проходит до и после мутаций.
3. **Мобильное меню без JavaScript.** Раньше показывалась неработающая кнопка. Теперь enhanced-кнопка появляется после подключения обработчиков, а при отключённом JavaScript доступно нативное меню `<details>` с теми же разделами и оформлением.
4. **Reduced motion и клавиатура.** У меню отключён переход `visibility`, который при очень быстром Tab оставлял ссылки временно недоступными даже после открытия. Программная прокрутка активной вкладки товара теперь использует `auto` при `prefers-reduced-motion`, вместо безусловного `smooth`.
5. **Фокус Telegram/Viber.** Голубая рамка Telegram давала около 2,95:1 на кремовой поверхности. Общая бордовая рамка даёт около 6,97:1. В подвале сохранена светлая рамка, официальные цвета бейджей сохранены. Браузерный сценарий измеряет контраст рамки и проверяет сохранение формы таблетки.

Концепция, иллюстрации, анимации портрета, товарные данные, цены, OLX, canonical, маршруты и SEO сохранены. Зависимости не добавлялись. Новые команды проверки перечислены в README.

## Повторение браузерного аудита

Сначала собрать проект и оставить preview запущенным:

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4321
```

В другом терминале указать существующую установку Playwright, если модуль не доступен из проекта:

```powershell
$env:TANMEK_PLAYWRIGHT_MODULE = Join-Path $env:TEMP 'tanmek-contact-qa/node_modules/playwright'
npm run check:ui
```

Этот путь соответствует текущему компьютеру. На другом компьютере указать свой путь к уже установленному модулю. `TANMEK_BROWSER_PATH` позволяет задать браузер; без него сценарий использует установленный Edge/Chrome или Chromium Playwright. `TANMEK_PREVIEW_URL` переопределяет адрес preview. Для повторения только интерактивных сценариев: `npm run check:ui -- --functional-only`.

Мутационный аудит не требует Playwright или preview: `npm run check:design`.

## Границы проверки и готовность

Воспроизводимых ошибок в проверенной сборке не осталось. С технической стороны проект готов к публикации. Commit, push и публикация в этой сессии не выполнялись.

Safari, Firefox, физические телефоны/планшеты и открытие установленных приложений Telegram/Viber не проверялись. Эмуляция сенсорного ввода не заменяет физическое устройство. Вход в Telegram Web, доступность аккаунтов для реальной переписки и доставка сообщения требуют ручной проверки владельцем; тестовые сообщения не отправлялись. Progressive enhancement сохраняет обычную навигацию в браузерах без поддержки декоративных возможностей.

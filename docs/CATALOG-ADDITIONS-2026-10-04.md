# Добавление товаров — 4 октября 2026

> **Актуальное состояние:** все P40–P49 открыты для покупателей; разрешения на продажу и изображения отмечены как подтверждённые. По следующему указанию владельца цены новых товаров снижены вдвое с округлением до гривны. Ниже сохранён исторический аудит первоначальной подготовки: его цены и ограничения публикации больше не актуальны. Текущие цены, статус и проверки: [публикация каталога](CATALOG-PUBLICATION-2026-10-04.md).

В проект добавлены **10 карточек P40–P49 на украинском языке, все как черновики**. Новых товаров, открытых для заказа, пока нет. Обычная сборка сохраняет 39 существующих публичных товаров. Изменения внесены локально; публикация на GitHub Pages не выполнялась.

Причины: коммерческие разрешения для шести моделей ещё не подтверждены; отдельные права на фотографии/рендеры не подтверждены ни для одной новой карточки; собственные производственные испытания не проведены. Это отдельные проверки: наличие STL, разрешение на коммерческую печать и право использовать изображения не заменяют друг друга.

## Проверка проекта и просмотр

- `npm run validate:data`: все **49 JSON**, категории, ссылки и уникальность прошли проверку.
- `npm run prices:check`: существующие **33 рассчитываемые цены** совпадают с политикой; десять новых ориентиров сохраняются без выдуманной массы.
- `npm run check`: **0 ошибок, 0 предупреждений**; семь существующих диагностических подсказок Astro.
- `npm test`: **76 тестов прошли**, включая настоящую production-сборку и проверки её HTML, JSON-LD, sitemap, категорий, ссылок и отсутствия черновиков. Песочница сначала запретила дочерние процессы (`spawn EPERM`); повторный запуск с разрешённым выполнением прошёл.
- `npm run check:build`: проверка production-артефакта прошла.
- `npm run check:drafts`: проверены по HTTP **49 карточек, 10 страниц черновиков, четыре категории**, `noindex`, отсутствие предложений/кнопок заказа, обложки и порядок всех галерей. Временный сервер остановлен.
- Дубли SKU, URL-slug и названий не найдены. Порядок/популярные товары существующего каталога сохранены.
- В исходном каталоге есть фильтры категории/популярного, но **нет текстового поиска**. Новый поиск в рамках добавления товаров не внедрялся. Структура данных фильтров и категория каждой карточки проверены; интерактивные клики требуют оставшегося браузерного прогона.

Для частного просмотра: `npm run dev:drafts`, затем `http://127.0.0.1:4322/3D-Drukarnya/`. Обычная production-сборка игнорирует переключатель чернового просмотра, не создаёт страницы черновиков и не публикует их изображения. Новые карточки нельзя случайно обозначить как имеющиеся на складе или открыть для заказа, пока они находятся в состоянии `draft`.

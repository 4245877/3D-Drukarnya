# Перехід на українську версію — 22.10.2026

Зміни підготовлено в репозиторії. Публікація на GitHub Pages та перевірка
Search Console не виконувалися в межах цієї зміни.

## Що змінено

- Прибрані російські та англійські сторінки, перемикач мов і посилання в підвалі.
- 56 колишніх URL збережені як перенаправлення: `/en/` і `/ru/` → `/`,
  `/ru/catalog/` → `/catalog/`, 4 категорії та 49 товарів → відповідні основні URL.
- Карта `src/data/language-redirects.mjs` підключена до загальної конфігурації
  перенаправлень Astro. Кожна адреса веде прямо на кінцеву сторінку.
- Sitemap зменшено зі 118 до 62 основних URL. Перенаправлення не включаються
  також у навігацію та автоматичну відправку canonical URL в IndexNow.
- `hreflang` видалено: перекладів більше немає. HTML, Open Graph і JSON-LD
  повідомляють лише основну мову (`uk`, `uk_UA`, `uk-UA` відповідно).
- Українські URL, title, description, H1, видимий контент, англійські технічні
  терміни, Product/Offer, BreadcrumbList, FAQ та зображення збережені.
- Архівні російські назви товарів і категорій, а також англійські пошукові
  терміни збережено в `meta keywords` відповідних основних сторінок через
  `src/data/search-terms.mjs`. Непов'язані сторінки не отримують ці назви.
  Новим товарам не потрібен переклад для проходження валідації.
- `robots.txt`, верифікація Search Console та ключ IndexNow не змінені.
  Старі адреси залишаються відкритими для обходу, щоб роботи бачили перенаправлення.

## Обмеження SEO

GitHub Pages віддає статичні файли й не надає конфігурації серверних 301/308
для цієї збірки. Використано наявний механізм Astro: відповідь 200 з
`meta http-equiv="refresh" content="0;url=…"`, canonical на основну сторінку,
`noindex` для документа перенаправлення та резервне посилання без JavaScript.
Це не HTTP 301. Google трактує миттєве meta refresh як постійне
перенаправлення; серверні перенаправлення мають пріоритет, якщо хостинг
їх підтримує. [Google: перенаправлення](https://developers.google.com/search/docs/crawling-indexing/301-redirects),
[Astro: статичні перенаправлення](https://docs.astro.build/en/guides/routing/#redirects).

Google не використовує `meta keywords` для індексації чи ранжування.
Збереження цього тегу виконує вимогу зберегти пошукові назви, але не замінює
перекладений текст. Видалення перекладів може знизити релевантність для
російських та англійських запитів; гарантувати незмінні позиції неможливо.
Додаткові приховані тексти та недостовірні мовні альтернативи не додавалися.
[Google: підтримувані метатеги](https://developers.google.com/search/docs/crawling-indexing/special-tags),
[Google: визначення мови сторінки](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites).

## Перевірки

Локально пройдено: валідація 49 товарів, Astro check без помилок і попереджень
(6 інформаційних підказок), 81 тест із реальною production-збіркою, перевірка
артефакту та IndexNow dry-run на 62 URL. Зовнішні повідомлення про індексацію
не надсилалися.

`npm run validate:data`, `npm run check`, `npm test` і `npm run check:build`
перевіряють дані, типи та реальну production-збірку. Зокрема:

- усі колишні мовні URL існують як миттєві перенаправлення з правильним canonical;
- кінцева сторінка існує, а карта не створює ланцюжків перенаправлень;
- sitemap містить лише основні канонічні URL;
- сторінки не містять перемикача, `hreflang` чи посилань на колишні версії;
- JSON-LD відповідає основній мові, пошукові назви присутні в метаданих;
- збережено перевірки цін, попереджень, FAQ, крихт, посилань та зображень.

## Після публікації

1. Перевірити `/en/`, `/ru/`, `/ru/catalog/`, кожну категорію та кілька старих
   товарних URL у браузері. Вони мають відкривати відповідні основні сторінки.
2. Перевірити на живому сайті 62 URL у `sitemap.xml`, canonical та індексованість
   основних сторінок; за потреби повторно надіслати sitemap у Search Console.
   Не використовувати інструмент термінового видалення URL для цієї міграції.
3. Через URL Inspection перевірити кілька старих і нових адрес. Переобхід і
   вибір canonical пошуковою системою відбуваються поступово.
4. Порівнювати кліки, покази, позиції та запити російською й англійською до
   та після публікації; окремо стежити за 404, помилками перенаправлення та
   змінами вибраного Google canonical. Дані акаунта в репозиторії недоступні.
5. Зберігати перенаправлення для зовнішніх посилань і закладок. При переході
   на хостинг з керуванням HTTP застосувати ту саму карту як 301/308.
